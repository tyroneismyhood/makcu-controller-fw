# Project and Payment Support

MAKCU Controller Firmware is an open-source project maintained by **Keyrose Creative**.

## Technical help

For bugs, compatibility reports, and technical questions:

1. Review the repository documentation and existing issues.
2. Open a GitHub issue with the controller model, target platform, firmware version, connection layout, and relevant logs.
3. Do not include passwords, payment information, serial numbers, private license keys, or other sensitive information.

The project is provided as-is, with no warranty or guaranteed support response.

## Financial support

- Guaranteed compatibility
- Guaranteed technical support
- Guaranteed features or release dates
- Control over development decisions

## Payment questions and refunds

For accidental, duplicate, or unauthorized payments, contact **Keyrose Creative** as soon as possible and include the Stripe receipt number.

Refund requests will be reviewed individually. Approved refunds will be returned through the original payment method when possible.
